# Kurd Quiz Builder

وێبێکی سادە و بێ Backend بۆ دروستکردنی تاقیکردنەوە.

## تایبەتمەندییەکان
- UI بە کوردی دەمێنێتەوە.
- تەنها زمانی ناوەڕۆکی پرسیارەکان دەگۆڕدرێت.
- کوردی، English، العربية، Türkçe.
- چوار هەڵبژاردە و ڕاست/هەڵە.
- زیادکردن/سڕینەوە و دەستکاری پرسیار.
- وێنەی تاقیکردنەوە.
- Preview و نمرەدان.
- بێ API و بێ database؛ ڕاستەوخۆ لە GitHub Pages کار دەکات.

## GitHub Pages
1. ئەم فایلانە لە repository ـێکی نوێ دابنێ.
2. Settings → Pages.
3. Deploy from a branch → main → /root.
4. Save.

## گرنگ
ئەم وەشانە "AI generation" نییە؛ پرسیارە نموونەکان لە ناو `app.js` ـدان. بۆ دروستکردنی پرسیاری AI ـی ڕاستەقینە پێویستی بە backend/API هەیە تا API key ـەکە لە کۆدەکانی browser ـدا ئاشکرا نەبێت.
